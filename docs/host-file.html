The host file

instance/host.yaml in your private site says how the host running thermite is configured: its time zone, installation root, service account ids, listener ports, gateway addresses, optional plain-HTTP Guest listener, metrics overrides, Music Assistant libraries and mounted network shares. Get started shows how a private site is created and deployed.

This page lists every key the file may have. It is made from the declaration thermite check and thermite install check the file against, so it names every key the file takes and none it refuses.

A value is text, a number, true or false, a list or a mapping. Write text that could be read as something else in quotes: "3.1.1", "on", "010". instance/host.yaml is read with the same strict YAML rules as the house file, naming the line of any value that does not mean one thing.

The top level

KeyValueWhat it is
version1The format of the file: 1.
timezonetext, requiredThe host's IANA time zone name such as Etc/UTC.
roottextThe root-owned installation directory (default /srv/thermite).
http_portnumberThe native openHAB HTTP listener port on loopback (default 13602).
https_portnumberThe native openHAB HTTPS listener port on loopback (default 13603).
uidnumberThe positive non-root numeric user id of the thermite service account (default 9001).
gidnumberThe positive non-root numeric group id of the thermite service account (default 9001).
gatewaymappingHTTPS gateway listener port and bind addresses.
metricsmappingPrometheus, Grafana and node_exporter host overrides.
guest_httpmappingOpt-in plain-HTTP Guest listener restricted to listed client networks.
musicmappingOpt-in Music Assistant libraries and listener ports.
sharesmapping by share nameNetwork shares mounted by Thermite.

gateway.portnumberThe HTTPS gateway listener port (default 13601).
gateway.listenlist of textThis host's own IP addresses the HTTPS gateway binds besides loopback.

metrics.unitslist of textAdditional systemd unit names for node_exporter to report on.

guest_http

KeyValueWhat it is

shares

KeyValueWhat it is
shares.<share name>.typecifs or nfs, requiredThe network filesystem type.

shares.<share name>.sharetextThe SMB share name (and optional subdirectory), for cifs shares.

Checking as you type

Editors that understand JSON Schema complete and check the file as you type: start it with # yaml-language-server: $schema=https://spincyc.github.io/thermite/host.schema.json. The schema is made from the same declaration. It knows the names of the keys and the kinds of value; thermite check checks the rest, such as valid IANA time zones, non-colliding ports and allowed mount points.
