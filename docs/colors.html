Colors and the torch

thermite looks the same on the web and in a terminal: a torch, and a theme: colors with a dark and a light mode. Use a built-in theme, or write a small file that changes only what you want.

The torch

96px48px24px16px

It is one drawing, shown two ways: as SVG on the web, and as half-block characters in a terminal, two pixels to a character. This is the terminal one, cell for cell:

thermite theme show                          # in your terminal, in your theme
thermite theme export svg --out torch.svg    # for a page of your own

Your own theme

A theme file names itself, says which theme it starts from, and changes only what it wants. This one keeps the torch and turns the controls teal:

{
  "$schema": "https://spincyc.github.io/thermite/theme.schema.json",
  "name": "harbor",
  "description": "thermite with a sea-glass accent: the torch stays molten, the controls turn teal",
  "extends": "thermite",
  "dark": {
    "accent": "#4fc1c9",
    "accent-ink": "#04191b",
    "focus": "#9be7ea",
    "hues": ["#4fc1c9", "#7fd18b", "#d2a4ec", "#ffc24a", "#ff8a4c"]
  },
  "light": {
    "accent": "#11707a",
    "accent-ink": "#ffffff",
    "focus": "#0b5960",
    "hues": ["#11707a", "#2e7d32", "#7b3fa0", "#9a6700", "#c2410c"]
  }
}

Check it. thermite tells you about unknown roles and badly written colors, and about text too faint to read on its background:

thermite theme check harbor.json
thermite theme show --theme harbor.json --light
thermite theme export css --theme harbor.json

The contrast it asks for follows WCAG, the web's accessibility guidelines:

  • text on bg: at least 4.5:1
  • text on surface: at least 4.5:1
  • text on raised: at least 4.5:1
  • muted on bg: at least 4.5:1
  • muted on surface: at least 4.5:1
  • accent on bg: at least 3:1
  • accent-ink on accent: at least 4.5:1
  • focus on bg: at least 3:1
  • ok on bg: at least 3:1
  • busy on bg: at least 3:1
  • bad on bg: at least 3:1
  • info on bg: at least 3:1
  • flame on bg: at least 3:1
  • each hue on bg: at least 3:1

Editors that understand JSON Schema complete and check theme files as you type: start the file with "$schema": "https://spincyc.github.io/thermite/theme.schema.json". Download the schema, the thermite theme or harbor.
