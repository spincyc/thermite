## Run it your way

Try the [fictional example](start.html#try-the-example), install on an [existing Linux server](installation.html), or build a [standalone ISO](iso.html) for a dedicated machine. Review the [system requirements](requirements.html) before installing.

## What it controls

TVs, streaming boxes, AV receivers, projectors, speakers, and HDMI and USB switchers with compatible control interfaces. The [commands guide](commands.html) includes discovery and pairing tools.

[Colors and the bowl](colors.html) explains the shared theme and metalworking-inspired mark.
